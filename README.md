# Epson L120 driver for Apple Silicon macOS

[![Verify](https://github.com/Aedwon/epsonL120-printer-driver/actions/workflows/verify.yml/badge.svg)](https://github.com/Aedwon/epsonL120-printer-driver/actions/workflows/verify.yml)

A community driver package for using the **Epson L120** on modern Apple Silicon Macs. It builds on Gutenprint 5.3.5's real `escp2-l120` implementation and integrates it with the macOS CUPS printing system.

Version **0.1.0** has been physically verified on a real Epson L120: clean package install, automatic USB queue creation, normal CUPS printing, black text, and color output.

> This is an independent community project. It is not an Epson product and is not affiliated with or endorsed by Seiko Epson Corporation.

## Install

### 1. Download the release files

From the [latest GitHub Release](https://github.com/Aedwon/epsonL120-printer-driver/releases/latest), download:

- `EpsonL120-macOS-arm64-0.1.0.pkg`
- `SHA256SUMS.txt`

The release also includes `gutenprint-5.3.5-source.tar.xz` to satisfy the source-redistribution requirements for the bundled Gutenprint components.

### 2. Verify the package (recommended)

From the folder containing the downloaded files:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

The package should report `OK`.

### 3. Connect the printer

Connect the Epson L120 by USB and power it on before installing. The installer will create the printer queue automatically when the printer is detected.

### 4. Open the package

Open `EpsonL120-macOS-arm64-0.1.0.pkg` and follow the macOS Installer prompts.

The package is intentionally **unsigned and not notarized** because this project currently uses the free distribution route. A downloaded copy may therefore be blocked by Gatekeeper. If macOS blocks it, attempt to open it once, then go to **System Settings → Privacy & Security** and use **Open Anyway** for the package you verified.

### 5. Print normally

After installation, the printer queue is named:

```text
Epson_L120
```

It should be available in normal macOS print dialogs. No Homebrew, Xcode, or separate Gutenprint installation is required on a Mac installing the prebuilt package.

If the printer was not connected during installation, connect and power it on, then run:

```sh
sudo /Library/Printers/EpsonL120/bin/setup-queue
```

## Uninstall

A package installation includes its own uninstaller:

```sh
sudo /Library/Printers/EpsonL120/bin/uninstall-epson-l120
```

This removes the `Epson_L120` queue, the driver-owned files under `/Library/Printers/EpsonL120`, and the package receipt.

## Compatibility

Currently verified:

- Epson L120
- Apple Silicon (`arm64`)
- USB connection
- macOS CUPS 2.3.4
- native arm64 Gutenprint filter
- black/text printing
- CMYK and RGB color printing
- clean installation from the unsigned `.pkg`
- printing through the package-created `Epson_L120` queue

Not currently verified:

- Intel Macs
- other Epson models
- network/shared-printer configurations
- future CUPS versions after removal of legacy PPD/filter driver support

## How it works

```text
macOS application
      ↓
CUPS Epson_L120 queue
      ↓
Apple PDF-to-raster pipeline
      ↓
Gutenprint escp2-l120 filter
      ↓
macOS USB backend
      ↓
Epson L120
```

The project does **not** implement a guessed or reverse-engineered printer protocol. Printer data is generated by Gutenprint's existing Epson L120 ESC/P2 support.

All driver-owned runtime files live under:

```text
/Library/Printers/EpsonL120
```

The installer does not modify SIP-protected `/usr/libexec/cups/filter` and does not depend on another system-wide Gutenprint installation.

## Important limitation

The PPD/filter driver architecture used here is deprecated by CUPS. Version 0.1.0 solves the practical Epson L120 printing problem on the environment tested, but this architecture may require replacement or substantial maintenance as future macOS/CUPS releases remove legacy driver support.
